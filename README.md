# Snooze Button Roast

make.fun bounty entry: `u-carbon-forge-snooze-button-roast-14cbafc6`

`main.py` (pure Python 3.13 stdlib) writes a single roast line about an
alarm clock ringing at 6 AM on a Saturday to `/output/entry.txt`
(1 line, 190 characters, within the 200-character limit).

Run: `python3 main.py`
